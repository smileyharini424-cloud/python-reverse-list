# Reverse a List

## Explanation

This program reverses the order of elements in a list.

## Problem Statement

Write a Python program to reverse a list of numbers.

## Features

* Accepts a list of numbers
* Reverses the list
* Displays the original and reversed lists

## How It Works

The program uses Python list slicing with `[::-1]` to create a reversed list.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* List slicing

## Program Flow

1. Read the list
2. Convert values into integers
3. Reverse the list
4. Display the result

## Sample Input

```text
1 2 3 4 5
```

## Sample Output

```text
Original list: [1, 2, 3, 4, 5]
Reversed list: [5, 4, 3, 2, 1]
```
